# CMD Studios - Website (WIP)

Website for **CMD Studios** (Webdesign & Content Production).
The structure and UI are mostly done - content (copy, images, final domain) is still in progress.

## Tech
- Next.js
- React + TypeScript
- Tailwind CSS
- Framer Motion / GSAP

## What's inside
- Innovative Animations and Features
- Modern UI components & layout system
- Routing + scalable structure for future pages / updates

## Local Setup
```bash
npm install
npm dev
```

Work in progress. The codebase is already usable as a foundation for client projects and future iterations.
